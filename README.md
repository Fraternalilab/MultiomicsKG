# MultiomicsKG: AI-enabled Multiomics Knowledge Graphs for Biological Discovery

We present here a biologically contextualised framework for missense-variant interpretation based on a Multiomics Knowledge Graph and a large language model–assisted querying interface.

The graph integrates publicly available variant annotations with gene, transcript, protein, domain, clinical and residue-level structural information, together with features derived using structural bioinformatics tools. Explicit mappings between biological entities enable direct traversal from genomic variants to the corresponding protein residues and their functional and structural contexts, while preserving provenance and query traceability.

The framework can be accessed through Cypher or through natural-language requests translated into inspectable and executable graph queries. It is a transparent and reproducible resource for investigating the structural and functional context of genetic variation and establishes a structured retrieval layer for LLM-assisted biomedical analysis.

## Overview

There are two components of the project:

1. **MultiomicsKG Assembly**: code for integrating data from many multiomics sources and data generated by some bioinformatics tools, with the goal to output CSV files that can be imported as a Neo4J Knowledge Graph.

2. **MultiomicsKG LLM-Enabled Querying Interfaces**: two LLM-based querying interfaces are available. A Graph RAG (retrieval-augumented generation) based chatbot agent and an MCP server that can be used to connect your agent or other AI app (e.g., Claude Desktop) to the MultiomicsKG.

The project requires many dependencies to run properly, therefore the best approach is to run it using Docker Composer.


## Cloning the repository

The repository uses submodules from some of its dependencies.

```bash
git clone --recursive git@github.com:Fraternalilab/MultiomicsKG.git
```
